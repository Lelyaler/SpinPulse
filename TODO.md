# MatchPulse — Live Sports & Esports Betting Dashboard

Интерактивная high-performance платформа спортивных и киберспортивных событий в реальном времени с симуляцией живых котировок, купоном ставок (Betting Slip), виртуальным балансом и звуковыми микроинтерфейсами.

---

## 🎨 Концепция дизайна и цветовая палитра (Светлая премиальная тема)

Вместо типичной чёрной/тёмной темы используется **«Ice White & Emerald Fintech»**:
* **Основной фон (`bg-slate-50 / #f8fafc`)**: мягкий чистый светлый фон без режущей белизны.
* **Карточки и панели (`#ffffff`)**: белые поверхности с тонкими границами (`#e2e8f0`) и мягкими многослойными тенями (`box-shadow: 0 4px 20px -2px rgba(15, 23, 42, 0.05)`).
* **Акцентные цвета**:
  * **Emerald / Mint (`#059669` / `#10b981`)**: основной бренд-акцент, баланс, кнопка ставки, рост коэффициента.
  * **Electric Indigo (`#4f46e5` / `#6366f1`)**: бейджи live-статусов, выбранные исходы, активные табы.
  * **Coral Red (`#ef4444`)**: падение коэффициента, статус live-матча (пульсирующая точка).
* **Типографика**: `Plus Jakarta Sans` / `Inter`, акцентные моноширинные таймеры матчей (`JetBrains Mono` / `Space Mono`).

## 🧩 Ключевые модули и архитектура проекта

1. **Header & Wallet:**
   * Логотип `MatchPulse` с индикатором реального подключения Live Feed.
   * Виртуальный баланс кошелька (начальный депозит: $1,000.00).
   * Кнопка быстрого пополнения баланса (+ $500 тестовых кредитов).
   * Звуковой переключатель (вкл/выкл звуковые эффекты ставок и уведомлений).

2. **Категории и фильтры событий:**
   * Табы видов спорта: Футбол, Баскетбол, Теннис, CS2, Dota 2.
   * Фильтр: «Только Live», «Скоро начнутся», «Топ события».
   * Быстрый поиск по названию команд / лиг с мгновенной фильтрацией.

3. **Live Match Ticker & Odds Grid (Центральный экран):**
   * Карточки матчей с динамическим табло (счёт, минута матча, статистика владения / угловых / киллов).
   * Кнопки исходов (1, X, 2, Фора, Тотал больше/меньше).
   * **Движок симуляции live-котировок:**
     * Каждые 3–6 секунд случайные коэффициенты динамически меняются.
     * Анимация подсветки: зелёная вспышка при росте (+), красная при падении (-).
     * Возможность ставить поток на паузу (для удобного тестирования).

4. **Интерактивный купон ставок (Betting Slip — Правая панель):**
   * Добавление исходов в купон в 1 клик с плавной анимацией.
   * Режимы ставки:
     * **Одинар (Single)**: отдельные суммы на каждый исход.
     * **Экспресс (Express / Parlay)**: перемножение коэффициентов, расчет совокупного выигрыша и бонусного процента.
   * Быстрые кнопки сумм ($10, $25, $50, $100, Max).
   * Валидация баланса (нельзя поставить больше текущего депозита).
   * Принятие ставки с подтверждением и звуковым эффектом «кассового щелчка».

5. **История ставок (My Bets Drawer / Modal):**
   * Вкладка открытых ставок (Pending) и завершённых (Won / Lost).
   * Симулятор расчёта результата: кнопка «Завершить матч» для проверки выигрыша и начисления денег на баланс.

6. **Web Audio FX:**
   * Звук выбора исхода, звук успешного размещения ставки, звук выигрыша (на базе чистого Web Audio API без тяжёлых MP3-файлов).
