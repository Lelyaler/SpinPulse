# SpinPulse

Демо-интерфейс игрового лобби онлайн-казино с каталогом игр, системой бонусов и симулятором ставок.

**Демо**: [https://lelyaler.github.io/SpinPulse/](https://lelyaler.github.io/SpinPulse/)

---

## Основной функционал

- **Каталог игр**: фильтрация по категориям (Слоты, Live, Crash, Bonus Buy, Джекпоты), поиск по названию и провайдеру, добавление в избранное.
- **Интеграция игрового лобби**:
  - Запуск оригинальных слотов в адаптивном модальном окне через официальные демо-серверы провайдера с поддержкой полноэкранного режима.
- **Виртуальный баланс и сессия**:
  - Сохранение состояния (баланс, избранное, история сессии) в LocalStorage.
  - Боковая шторка активности сессии с быстрым повторным запуском игр.
  - Ежедневный бонус и промокоды с мгновенным пополнением баланса.
- **UI и визуальные элементы**:
  - Анимированный тикер джекпотов с динамическим приростом банка.
  - Лента недавних выигрышей игроков.
  - Звуковые эффекты действий и выигрышей с возможностью отключения звука.
  - Двуязычный интерфейс (RU / EN).

## Стек технологий

- **HTML5 & CSS3**: адаптивная верстка (CSS Grid, Flexbox, CSS переменные), методология БЭМ.
- **JavaScript (ES6+)**: модульная компонентная структура без тяжелых фреймворков.
- **HTML5 Canvas**: визуальные эффекты конфетти при крупных выигрышах.
- **Web Audio**: звуковые эффекты спинов и выигрышей через пул аудио-объектов.
- **Vite**: сборщик проекта и локальный dev-сервер.

## Установка и запуск

1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/Lelyaler/SpinPulse.git
   cd SpinPulse
   ```

2. Установить зависимости:
   ```bash
   npm install
   ```

3. Запустить режим разработки:
   ```bash
   npm run dev
   ```

4. Собрать production-билд:
   ```bash
   npm run build
   ```
