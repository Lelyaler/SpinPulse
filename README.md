# SpinPulse

> **Live Demo:** [https://lelyaler.github.io/SpinPulse/](https://lelyaler.github.io/SpinPulse/)

Интерактивный симулятор лобби онлайн-казино с каталогом игр, игровым автоматом, Колесом Фортуны, живым счётчиком джекпота и звуковыми эффектами.

## Основные возможности

- **Интерактивный слот-симулятор**: полноценная игра в модальном окне с выбором размера ставки ($10, $25, $50, $100), вращением барабанов, расчётом выигрышных комбинаций и зачислением на виртуальный баланс.
- **Интерфейс лобби**: витрины провайдеров (Pragmatic Play, Evolution, NetEnt, Hacksaw Gaming), адаптивная сетка карточек со статусами и быстрым запуском.
- **Колесо Фортуны**: физика вращения с замедлением, звуковые эффекты трещотки и праздничное конфетти при крупных множителях.
- **Прогрессивный джекпот**: динамический тикер джекпота с непрерывными микро-приростами.
- **Лента выигрышей в реальном времени**: поток недавних выигрышей с отображением множителей и слотов.
- **Каталог и фильтрация**: полнотекстовый поиск, фильтрация по категориям («Слоты», «Live», «Краш-игры») и провайдерам, сохранение избранных игр в LocalStorage.
- **Демо-баланс и история**: виртуальный банкролл, пополнение баланса в один клик, ежедневные награды и сохранение истории раундов.
- **Звуковой движок**: звуковые эффекты спинов, кликов и выигрышей с пулом аудио-инстансов и возможностью отключения звука.
- **Локализация**: поддержка переключения языков интерфейса (RU / EN).

```bash

# Запуск dev-сервера

# Сборка проекта
npm run build
```
