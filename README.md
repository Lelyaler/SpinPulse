# SpinPulse

> **Live Demo:** [https://lelyaler.github.io/SpinPulse/](https://lelyaler.github.io/SpinPulse/)

Интерактивный симулятор лобби онлайн-казино с каталогом игр, Колесом Фортуны, живым счётчиком джекпота, лентой недавних выигрышей и процедурным звуком.

## Основные возможности

- **Интерфейс лобби**: витрины провайдеров (Pragmatic Play, Evolution, NetEnt, Hacksaw Gaming), адаптивная сетка карточек со статусами и быстрым просмотром.
- **Интерактивное Колесо Фортуны**: физика вращения с замедлением, синтезированный звук трещотки и фейерверк конфетти при крупных множителях.
- **Прогрессивный джекпот**: динамический тикер джекпота с непрерывными микро-приростами.
- **Лента Live Drops**: поток недавних выигрышей в реальном времени с отображением множителей и слотов.
- **Каталог и фильтрация**: полнотекстовый поиск, фильтрация по категориям («Слоты», «Live», «Краш-игры», «Настольные») и провайдерам, сохранение избранных игр в LocalStorage.
- **Демо-баланс**: виртуальный банкролл, пополнение баланса в один клик, ежедневные награды и история раундов.
- **Процедурный звук**: аудиоэффекты (клики, вращение колеса, звон монет) генерируются в браузере через Web Audio API без внешних аудиофайлов.
- **Локализация**: поддержка переключения языков интерфейса (RU / EN).
